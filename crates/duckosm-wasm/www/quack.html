duckOSM quack

The features table of QuackOSM (feature_id, tags, geometry) of an .osm.pbf file, made in this browser by duckOSM's Rust engine. The file stays on your computer.

1. The file

Threads A setting for each part: the threads of the cut, the tile workers that make the rows of the tiles (each with one thread), and the threads of the join of the parts. A number larger than the cores can help when the threads wait for the browser storage. The default is 8, or the cores that the browser reports when it is more (at most 16). In one run (not tile by tile), the threads of the cut are the threads of the run.
